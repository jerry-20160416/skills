# 钉钉知识库下载工具操作手册

## 工具概述

**脚本名称**：`dingtalk-download-structured.py`

**功能**：批量下载钉钉知识库文件，**递归下载所有嵌套文件夹，保持完整文件夹结构**

**特点**：
- 用户手动登录，无需处理认证问题
- **自动递归下载所有子文件夹**
- 按知识库原结构创建本地文件夹
- 支持增量下载（已存在文件自动跳过）
- 实时显示下载进度和统计

## 注意事项

### 1. 下载策略

| 情况 | 行为 |
|------|------|
| 文件已存在 | 自动跳过，显示 ⏭️ |
| 文件夹已下载 | 自动跳过 |
| 子文件夹 | **自动递归下载** |

### 2. 限制说明

- 大文件夹可能需要较长时间
- 保持浏览器打开，关闭会停止下载
- 网络不稳定可能导致部分失败

### 3. 常见问题

| 问题 | 解决方案 |
|------|----------|
| 浏览器未打开 | 运行 `playwright install chromium` |
| 下载失败 | 检查网络，重新运行（已下载会跳过） |
| 文件名乱码 | 脚本自动处理非法字符 |
| 路径过长 | Windows 路径限制 260 字符 |

## 增量下载

支持断点续传，已下载的文件会自动跳过。可以多次运行：

```bash
# 第一次运行（下载所有文件）
python dingtalk-download-structured.py

# 中断后再次运行（只下载未完成的文件）
python dingtalk-download-structured.py
```

---

## 停止下载

按 `Ctrl+C` 停止下载，已下载的文件会保留。
